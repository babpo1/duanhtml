HUONG DAN SU DUNG

1. Giai nen tep ZIP.
2. Mo thu muc, bam dup vao index.html de xem trang chu tren trinh duyet.
3. Ba trang HTML dung chung file style.css; hay de tat ca 4 file trong cung mot thu muc.
4. Tim va thay [Ten cua ban] bang ten cua ban trong cac file HTML.
5. De bai yeu cau hinh anh cua rieng ban: hay thay cac dia chi anh images.unsplash.com bang anh cua ban. Co the tao thu muc images va dung vi du src="images/anh-cua-ban.jpg".
6. Kiem tra HTML tai https://validator.w3.org/ va kha nang truy cap tai https://wave.webaim.org/.
7. Neu nop len GitHub Pages, tai len ca 3 file HTML va style.css, sau do bat GitHub Pages trong Settings > Pages.

Cac yeu cau da duoc ap dung:
- 3 trang HTML rieng va lien ket dieu huong
- Skip link chi hien thi khi duoc focus
- Flexbox cho thanh dieu huong
- Grid hai cot o phan gioi thieu
- Box model voi border, padding, margin
- Hieu ung hover
- nth-child tao mau the xen ke
- Alt text cho anh va bo cuc responsive
